# Стопки слов / Word Piles 0.1.0

Дополнение для компьютерного Anki на macOS, Windows и Linux.
Проверено с Anki **25.09.4**, Python 3.13 и Qt 6. На мобильном Anki Python-дополнения не работают.

## Установка

1. Anki → **Инструменты → Дополнения → Установить из файла…**.
2. Выбрать `Word_Piles_0.1.0.ankiaddon`.
3. Перезапустить Anki.
4. **Инструменты → Стопки слов…** или **⌘⇧J** на Mac / **Ctrl+Shift+J** на Windows и Linux.

## Две стопки

**Слова за день** — все слова, по которым был хотя бы один оценённый ответ за выбранный учебный день.
Включает новые и повторяемые. Оба направления одной записи объединяются в строку.

**Трудные сейчас** — накопительный список по существующей истории Anki:

- Слово входит после 10 ответов **Снова** за один учебный день (суммарно по направлениям).
- В день попадания успешные попытки его не убирают.
- В следующий день, когда слово встретится, достаточно одного ответа 2, 3 или 4, если за этот день нет ни одного **Снова**.
- Если после такого успеха в тот же день появляется **Снова**, слово возвращается: день уже не чистый.
- Если слово не встречалось, статус не меняется.
- После чистого дня оно может войти заново, когда опять наберёт дневной порог.

2 (**Трудно**) — успешное вспоминание, не ошибка. Ошибкой считается только 1 (**Снова**).
Считаются все реальные ответы, включая обучение и переучивание.
Ручные записи перепланирования в журнале не учитываются.

Учебный день начинается в час, указанный в настройках Anki. Таймеров занятий нет.
История группируется по текущему часовому поясу компьютера и текущей границе дня.
Изменение границы дня, часового пояса или порога пересчитывает исторические списки.

Счётчики во вкладке трудных показывают последний день, когда слово встречалось.
Выбранная сверху дата меняет только список за день; трудные всегда показывают текущее состояние.

## Копирование

- **Копировать слова** — по одному слову на строку.
- **С переводами** или **⌘/Ctrl+C** — слово и перевод.
- **Для нейронки** или **⌘/Ctrl+Shift+C** — слова, переводы, оценки по направлениям и задание на практику.

Если выделены строки, копируются они. Иначе — весь список, видимый после фильтрации и поиска.
Двойной щелчок или **Открыть в Anki** открывает выбранные записи в браузере Anki.

## Настройки и данные

В **Настройках** можно изменить порог и поля слова/перевода для каждого типа записи.
Для типа Language автоматически выбираются Word и Translation, для Basic — Front и Back.
HTML и звуковые метки удаляются при экспорте, сами поля остаются без изменений.

Списки строятся заново из журнала Anki. Учитываются уже существующие ответы;
не нужно сначала заниматься с установленным дополнением.
Отмена ответа и синхронизация отражаются при обновлении. Открытое окно обновляется после операций Anki;
также есть кнопка **Обновить**. Окно проверяет переход суток раз в минуту.

Данные не передаются в сеть. Копирование только помещает текст в буфер.
Карточки, интервалы, теги, оценки и журнал дополнение не изменяет.
Две отдельные записи с одинаковым словом не объединяются автоматически, чтобы не смешать разные значения.
Название направления берётся из шаблона Anki (например, Card 1 / Card 2).

Чтобы использовать на другом компьютере: установить тот же .ankiaddon и синхронизировать
коллекцию штатным способом. Списки восстановятся из журнала; настройки дополнения
передаются отдельно через файл JSON в окне стандартных настроек дополнения.

## Проверка и исходники

В архиве исходников есть 13 независимых тестов правил и проверка интеграции с
Anki/Qt. В ходе разработки проверены чтение копии реальной коллекции,
объединение направлений, обе таблицы, поиск, выбор полей и копирование в буфер.
Исходники написаны для этого проекта; код сторонних дополнений не включён.

Для тестов правил: `python3 -m unittest discover -s tests -v` из корня архива.
Для интеграционного теста нужен Python из установки Anki и PyQt6.

Это пробная версия; проверка длительной ежедневной эксплуатации ещё впереди.
