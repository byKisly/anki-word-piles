# Стопки слов

`threshold`: число ответов **Снова** за один учебный день для входа в трудные (по умолчанию 10).

`fields`: соответствия полей по имени типа записи. Удобнее менять в окне **Стопки слов → Настройки**.

Списки вычисляются заново из журнала Anki. Изменение порога пересчитывает и прошлые дни.
Дополнение не меняет интервалы, оценки, теги или карточки. Отменённые ответы исчезают из расчёта после **Обновить**.
